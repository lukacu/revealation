# Revealation styles

The stylesheet split follows application responsibility rather than feature history.

- `app.css` — core shell, editor, dialogs, toolbar and responsive layout.
- `sidebar.css` — slide/subslide sidebar, Thumbnail/Outline view and thumbnail surfaces.
- `interactive.css` — editor/dialog styling for the `interactive` content type.

Presentation-deck CSS that must also appear in preview/export is generated by the rendering core (`DECK_CONTENT_CSS`) rather than living only in these editor stylesheets.
